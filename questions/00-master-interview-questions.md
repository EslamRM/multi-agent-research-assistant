# Interview Question Bank

This question bank is built from the actual repository implementation and is intended for reuse in technical interviews, architecture reviews, and project defense.

## Question sets

- [questions/01-architecture-and-multi-agent.md](01-architecture-and-multi-agent.md): architecture, orchestration, and state design
- [questions/02-production-security-and-defense.md](02-production-security-and-defense.md): productionization, security, and defense-level follow-ups

## Core themes

- Why use LangGraph instead of a single orchestration function?
- Why separate planning, evidence gathering, synthesis, and reporting?
- Why is typed state and validation important here?
- What are the trade-offs between retrieval, long context, and provider abstraction?
- How would you improve reliability, security, observability, and cost control before production release?
